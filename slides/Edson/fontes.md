# Novas fontes e créditos — Edson

As referências e os créditos dos slides iniciais estão preservados em [../fontes.md](../fontes.md). Este arquivo recebe as novas fontes usadas na parte de Edson.

Ao adicionar dados ou imagens, registre a informação neste arquivo e mantenha a indicação de fonte ou crédito no slide quando necessário. Reúna os novos registros de Caio e Diogo para atualizar manualmente o slide final de referências; o compositor não faz essa atualização.

## Referências e dados adicionados

Nenhuma fonte nova nesta divisão inicial.

Para cada nova fonte, informe: arquivo ou ID do slide, referência completa, link, data de consulta e, quando houver dados, tabela/página, unidade, ano e recorte utilizado.

## Imagens adicionadas

Nenhuma imagem nova nesta divisão inicial.

Para cada imagem em `assets/`, informe: nome do arquivo, autor, página de origem, licença ou autorização, crédito exigido e adaptações realizadas.
